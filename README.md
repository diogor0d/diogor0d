## A few things I’m building

### [PlateOS](https://github.com/diogor0d/plate-os)
**Nutrition tracking, with a review step.** Scan a barcode, photograph a label, or describe a meal. The model extracts the information; code calculates the totals. You confirm what gets logged.

<sub>Python · FastAPI · React · PostgreSQL · Offline-first PWA</sub>

### [Clipboard Mate](https://github.com/diogor0d/clipboard-mate)
**A shared clipboard you control.** Send text between iPhone, Windows, and macOS through a server you host. Publishing and copying are explicit actions; nothing watches your local clipboard in the background.

<sub>TypeScript · Fastify · Electron · SQLite · Apple Shortcuts</sub>

### [Media Manager](https://github.com/diogor0d/media-manager)
**The file is too big. The format is wrong.** Download, convert, and compress media on your own server, with output estimates before processing and a history to recover results from.

<sub>Python · FastAPI · FFmpeg · Docker · MeTube</sub>

### [PaperSpotlights](https://github.com/diogor0d/paper-spotlights)
**Stage lighting, built out of Minecraft.** Build a fixture, aim it with a lens, and turn a clock to dim it. Native light blocks, no client mod, no resource pack.

<sub>Java · Paper API · Maven · No runtime dependencies</sub>
